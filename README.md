# 🎓 EduPlay - Plataforma de Juegos y Actividades Educativas

Plataforma web interactiva para crear, jugar y compartir actividades educativas interactivas.

## 🚀 Características

- 🎮 **Variedad de Actividades**: Opción múltiple, Verdadero/Falso, Emparejar, Ahorcado, Sopa de letras y más.
- 🤖 **Generador Inteligente con IA**: Creación rápida de preguntas y dinámicas educativas.
- 📊 **Seguimiento y Resultados**: Puntuaciones, tiempos y retroalimentación para estudiantes.
- 🎨 **Diseño Moderno y Responsivo**: Interfaz fluida y optimizada para cualquier dispositivo.
